## The naming rule

Every Radhiant organisational file is named:

```
Date_DEPT_TitleOfDocument_FileType_Version
```

Date first as `YYYYMMDD`, underscores between sections, no spaces, no special characters, no person names.

Example: `20260619_MRKT_BrandGuidelineStrategy_GDE_V1.2.docx`

**Department codes:** CEO, MGT, ADM, IT, MAM, FIN, HR, SAL, MRKT, OPS

**Document type codes:** SOP, POL, FRM, RPT, REG, MIN, AGR, INV, LTR, GDE

## Files that go outside Radhiant

A file sent to someone outside the company is named for the person receiving it:

```
Date_Entity_Counterparty_PlainDocumentTitle
```

No department code, no file type code and no version number. Never put a patient name in a file name.

## Where documents live

Approved Radhiant documents are filed in the **Radhiant Working Folders** SharePoint libraries: Company-Wide, Finance, Marketing and Sales, Operations, plus the CEO-Office library. Each library has numbered subfolders and a `00_CONTENTS` note. Superseded versions move to `_Archive`. `_Restricted` subfolders are limited to named individuals.

Drafts stay out of the libraries until approved.
